# Virtua `000.015.002.2026`

Tag format: `Major.Minor.Sub.Year` → `000.015.002.2026` (Major.Minor.Sub.Year = 000.015.002.2026).

Build: `0.010.19.11.26`

## Highlights

- **Port** on PC and **Portable Sync** on Android:
  - PC **Port** panel has **Pair New** (fresh QR with a rotated local token), **Sync** (send the current PC snapshot to the connected phone), and a **Trusted Devices** list with revoke/re-allow.
  - Android has a Portable Sync tab with a local QR scanner, manual entry, pull/push, and the same trusted-device view.
  - Still opt-in, LAN/mDNS/Tailscale only; no cloud relay.
- Manual GitHub update check in **Data → system**; GitHub is contacted only after clicking **Check for update**. The check uses the latest release and still falls back to the version tag if needed.
- Local-first Android companion:
  - Phone mode runs GGUF models on-device with `llama-android` and keeps chats/characters/settings/avatars app-private.
  - Desktop link mode connects over LAN/mDNS/Tailscale with a pairing token; no cloud relay.
  - SAF import/export for backups, GGUF models, and user-provided VRM avatars.
  - Later sync with the desktop via explicit pull/push over the local bridge.
- Transactional desktop restore and Android bundle export with copied `.vrm` files; no avatar or model is bundled in the APK.

## Release assets

- `Virtua-Setup-0.10.0-x64.exe` — Windows x64 NSIS setup (per-user install, desktop and Start menu shortcuts). It is unsigned, so Windows SmartScreen may ask you to choose **More info → Run anyway**.
- `app-debug.apk` — Android arm64-v8a debug APK for the local-first companion, including the local QR scanner (camera permission used only when you tap **Scan PC QR**). Install with `adb install -r app-debug.apk` or open it on the phone.

Both assets are local-only builds. No VRM, GGUF model, user database, cloud key, or telemetry is bundled.

## Privacy

No telemetry, no cloud APIs, no runtime network calls by default. The only outbound requests are the manual update check and the opt-in local/Tailscale phone bridge.
